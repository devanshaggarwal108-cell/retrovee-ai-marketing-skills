# Retail Seo Opportunities

Start with the existing catalogue and any available search data. Separate observed impressions from query ideas. Use an intent-to-page map to decide whether to improve a product, collection or guide. Include an expected benefit, effort and confidence for each proposal.
For opportunities with Search Console data, compare impressions and CTR by page, then check whether the corresponding query and page fit the offer. With public evidence only, present candidates without invented difficulty, volume or conversion gains.
Example: route purchase-intent recorder terms to the product page. Consider a gift guide only when it adds a useful comparison and has a distinct reader intent.

Save findings and proposed edits in a local draft. Include current and proposed values, evidence, and the checks to run after release. Live changes and publishing require the user’s approval after reviewing the draft.
